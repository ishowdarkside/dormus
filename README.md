Dormus 🏡

A Real-Time Family Management & Organization Platform

Dormus is a full-stack web application designed to simplify and centralize family organization. It acts as a digital family manager — helping households coordinate tasks, finances, communication, and daily life in one shared space.
Built with React, Golang, and PostgreSQL, Dormus focuses heavily on real-time collaboration, ensuring that every update is instantly reflected across all connected users via WebSockets.

✨ Core Features

👨‍👩‍👧‍👦 Family Management

- Add, remove, and manage family members
- Role-based access and permissions
- Shared workspace for the entire family

✅ Task Management (Kanban Board)

- Visual Kanban board for tasks
- Assign tasks to family members
- Track progress in real time

🔐 Authentication & Authorization

- Secure user authentication
- Protected routes and actions
- Authorization based on family roles

📝 Notes

- Shared and personal notes
- Real-time updates for collaborative notes
- Simple and fast access

💰 Financial Organizer

- Budget planning
- Bill tracking with due dates
- Overview of upcoming and paid expenses

🛒 Shopping List

- Shared shopping lists
- Live updates when items are added or removed
- Prevents duplicate purchases

📅 Shared Calendar

- Centralized family calendar
- Events visible to all members
- Ideal for planning schedules, reminders, and deadlines

💬 Real-Time Chat

- Built-in family chat
- Instant messaging using WebSockets
- Keeps communication inside the app

⚡ Real-Time First Architecture

Dormus is built around real-time synchronization.
All collaborative features (tasks, chat, notes, lists, calendar updates) are powered by WebSockets, ensuring:

- Instant UI updates
- No manual refreshes
- Seamless multi-user experience

🛠 Tech Stack
- Frontend: React, Modern component-based architecture, Real-time state updates
- Backend: Golang, WebSocket-driven communication, REST + real-time event handling
- Database: PostgreSQL, Structured relational data, Optimized for multi-user consistency

🎯 Project Goal

The goal of Dormus is to replace scattered tools (notes apps, calendars, chats, to-do lists, finance trackers) with one unified platform tailored specifically for families.

It’s designed to be:
- Practical
- Fast
- Real-time
- Easy to use
- Scalable

🚧 Project Status

Dormus is actively being developed and improved.
Future plans include performance optimizations, UX improvements, and additional family-oriented features.
